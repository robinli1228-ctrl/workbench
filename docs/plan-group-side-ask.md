# 群聊卡片侧聊实施计划

状态：开发、独立审核及隔离真实验证完成；待合并，未部署。

目标：Claude / Codex 群聊 Agent 卡片可打开临时只读侧聊，复用会话页侧聊，不派发群聊任务、不改主会话和历史。

## 边界与接口

- 提取 `public/native-side-ask.js`，共享输入、附件、模型选择、轮询、清空及消息展示；Sessions 保留原有行为。
- `src/group-side-ask.mjs` 从公开消息及其原始 Run 解析 node/runtime/native session/model。禁止用角色当前绑定替代原记录，拒绝跨群聊、缺失会话和不支持的 CLI。
- Home 增加消息侧聊 GET/POST 适配，POST 每次重新解析来源。选中消息作为引用传入临时侧聊，用户问题仍单独展示；使用原生会话当前上下文，不声称历史时间点快照。
- 群聊右侧增加侧聊标签与卡片入口。不同卡片切换遇草稿、上传或回答中须确认；同卡片保留侧聊。关闭仅收起面板，清空才删除临时侧聊；跨群聊暂隐藏来源，保留显式清空入口。
- 沿用只读 CLI、容量限制和临时会话清理，不改变主任务调度、服务或转发。

## 实施与验证

1. 本地回归先证明来源适配缺失：原 Run 绑定、改过角色、内部消息、跨群聊、离线和 CLI 不支持；补上最小适配并验证。
2. 提取共享面板并接入 Sessions / 群聊；验证发送引用、仅首轮提示、源会话推进后引用重带、附件和模型、切卡草稿保护、迟到响应、清空及同卡重开。
3. 用隔离 Home / Worker 与真实浏览器检查两种 CLI 入口、交互、中文和窄屏。真实 CLI 使用专用临时会话，不接管业务会话；无法完成的真实验证必须说明。
4. npm ci、npm run check、相关及完整测试，独立整分支审核。截图留在忽略目录，更新当前行为说明，提交新 PR；不合并、不部署、不重启。

测试和验收证据仅留 `.local/group-side-ask/`，不提交私人配置、截图或测试脚本。

## 验证记录

- 相关回归 48 项通过，覆盖原 Run 来源、跨聊天拒绝、旧 Worker 拒绝、目录变化、卡片引用首次注入与父会话推进后重新注入、容量拒绝及既有侧聊生命周期。
- 全量 372 项通过。测试进程剥离继承的 CLI 凭据环境，使用规范化临时路径和 CommonJS 临时 CLI 测试目录；未改变产品运行配置。
- Edge + 隔离 Home/Worker：Claude 与 Codex 真实临时会话均返回选中卡片和原会话的独立校验词；桌面与窄屏可用。
- 独立审核复验：切卡 GET 期间锁定输入/附件/模型/发送/清空；跨项目或同项目跨群聊隐藏旧侧聊，返回原群聊恢复草稿；长问题可展开全文。
- 附件真实链路发现既有 Worker 下载侧聊附件路由未被分发，补回同一处理器后，真实上传、下载及 Claude 只读工具读取通过；认证与附件归属检查保持不变。
- 最终浏览器验收通过：同卡重开保留回答，清空临时侧聊有效；原始群聊消息、Run 与任务列表逐项比较不变。
