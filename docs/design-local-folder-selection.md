# 本机目录选择与精确绑定

状态：本地实现完成；隔离 Home/Worker、真实 Edge 页面及权限回归通过。原准备失败占位问题已补偿释放并增加失败重试、迟到激活和活动进程保护验证。未部署、未重启。

## 目标与现状

新建原生会话、新建项目群聊均可浏览本机操作系统允许访问的目录，包括桌面、下载与已挂载磁盘；只绑定最终选择的目录，不因浏览给所有 Agent 增加整盘权限。保留已有文件、历史及活动任务，远端设备的现有根目录限制不变。

原实现将浏览和执行目录校验都限制在 `WORKER_ROOTS`；现实现通过 `folder-access.mjs` 分离人类浏览和具体绑定授权。`POST /api/projects` 接收最终选定的 `localRoot`，为空时保留默认创建流程，不把 `/` 加入执行根目录。

这是现有 Home、Worker、创建表单的一次权限链路调整，不另建控制服务，不引入递归扫描或文件索引。

## 页面行为

1. 本机目录选择器可进入文件系统、用户主目录及已挂载磁盘，支持绝对路径输入、逐级浏览和分页。只读取当前层级的目录项元数据，不读取文件正文、不递归查找。无权访问或磁盘卸载时显示实际错误，不尝试提权。
2. 原生会话继续使用现有设备、CLI、标题和工作目录表单；选中普通文件时仍只采用其父目录。只有最终提交创建时申请该工作目录；取消浏览不留下授权。续接历史会话仍固定原目录。
3. 新建项目群聊增加“指定已有目录”，选择的是最终项目目录，不再悄悄附加一个同名子目录。未选择时保留当前默认目录创建流程。既有项目内新增群聊沿用该项目绑定，不借此重新授权目录。
4. 选择已有目录不清空、覆盖、移动文件，不自动初始化 Git、克隆仓库、启用同步或重写 AGENTS.md；已有项目归属冲突明确拒绝。后续用户显式配置仓库等行为沿用原流程。
5. 远端选择器保持原允许目录；旧 Worker 不支持本机精确授权时明确提示升级，不降级为全盘权限。

## 浏览与执行分离

沿用现有人类认证 API，仅本机 Worker 的新能力允许全盘目录元数据浏览。Agent 工具凭证不能调用此入口；浏览结果不是执行授权。

最终绑定沿用现有项目创建、原生会话准备接口，由 Home 从人类请求生成带稳定操作 ID 的授权意图。Worker 重新解析最终 canonical path，确认其为可用目录，校验归属和占用；Home 依据 Worker 回执持久化绑定后才激活授权。失败或未知结果只可按原操作 ID 查询/恢复，不能改成路径即默认已授权。

授权身份包含设备、用途（项目或独立原生会话）、稳定项目/会话登记 ID、canonical root、授权操作 ID 和状态。它不是一份追加到全局 WORKER_ROOTS 的目录清单。执行、附件、文档、仓库、终端与同步请求只消费其实际所属项目/会话的授权，不能由输入路径或另一个项目的授权推导权限。现有配置根目录保持原样，新增授权不扩大原有角色权限模式或原生 CLI 的权限开关。

授权范围为选中目录及其子目录；解析真实路径后拒绝通过符号链接或路径穿越访问其父级、兄弟目录和其他磁盘。目录被替换、绑定身份不符、设备离线或授权状态不明确时失败关闭。文件系统根目录可浏览，但不能作为这种精确绑定授权，避免以单次选择变相开放整盘。

解绑、删除项目或放弃未完成创建时，撤销相应授权，不删除目录或原生历史。历史记录仍保留，但历史记录本身不能生成新授权。已有活动执行与终端继续保留其冻结目录及既有锁；不在运行时强行切换或撤销其执行环境。

权限说明须如实表述：以上是 Workbench 目录路由与授权边界，不声称为已启用原生 bypass 的 CLI 增加操作系统沙箱。

## 代码边界

- `src/folders.mjs`：本机浏览的目录元数据边界，保留远端限制。
- `src/home.mjs`：人类绑定意图、幂等参数、能力检查；不接受 Agent 凭证新增授权。
- `src/worker.mjs` 及其现有目录/终端调用方：按请求实际身份消费精确授权，保留原根目录及活动锁。
- `src/home.mjs` 的创建分支区分默认创建与指定已有目录；原 `src/project-space.mjs` 默认流程不变。
- `public/project-setup.js`、`public/project-settings.js`、`public/native-sessions.js` 和必要的创建提交处理：两处选择器和最终目录显示一致；不覆盖其他人的图标、布局改动。
- 复用当前 Store，新增授权记录不迁移或重写历史任务；具体字段与回执顺序在实施计划中锁定。

## 验收

- 先以隔离数据测试原配置根目录之外的目录：浏览可用、取消无授权、创建后只有绑定身份可用；另一个项目、父级和兄弟目录仍拒绝。
- 覆盖符号链接逃逸、路径替换、无权限、磁盘不存在、根目录绑定、双击/重试、创建中断与未完成授权恢复。
- 覆盖旧 Worker、远端 Worker、Agent 凭证调用、已有目录文件哈希、既有项目归属、活动任务及终端占用拒绝。
- 用隔离 Home/Worker 与真实浏览器完成会话和群聊选择本机目录，验证最终绑定、取消与错误反馈；目录位于项目内部的隔离测试区但在测试 Worker 的配置根之外。额外只读浏览实际桌面/下载/挂载入口，不写入用户目录。
- 独立审查身份与授权边界；现有全量测试通过。不能只凭选择器能显示目录认定完成，须证明后续执行校验能识别绑定且不能借用他人授权。
