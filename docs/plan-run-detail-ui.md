# 运行详情前端调整实施计划

> 使用 executing-plans 在当前隔离工作树实施；保留此前未提交的角色模型标签。

**Goal:** 落实用户确认的运行详情设计，仅调整前端呈现。
**Architecture:** 沿用已有任务、Run、事件、历史原文与文件接口；前端将输出及工具事件按顺序组合，复用会话页 activityBlock 和 Markdown 展示。无后端、统计口径或调度变更。
**Tech Stack:** JavaScript ESM、原生 DOM/CSS、现有 Edge/Playwright。
**Spec:** 本会话确认的第五版设计；本地预览位于 .local/run-detail-design-20261025/design-v5.html。

## 约束与验收重点
- 保留标题、时间、状态、停止及关闭；会话编号展示后8位，复制仍取完整值。
- 移除副标题、工作区、Git卡片；Token按M展示，原始数值可悬浮查看。未知不能显示零。Codex明确会话累计，其他运行时保留其既有口径。
- 输入独立首个Tab；运行记录无用户输入及头像/角色/模型行，文本与工具保持原事件顺序；同一工具状态合并，错误不丢失。
- 复用工具详情/文件预览，刷新保留展开状态与滚动位置，不新增拉取/轮询。
- 产物只美化现有报告、交付及文件入口；结果原文保留分段读取与完整复制。
- 前端不得执行或自动发送任务，隔离验证不得连接生产Worker。
