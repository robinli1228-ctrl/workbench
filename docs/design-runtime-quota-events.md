## 数据流程

正常 CLI 额度事件 → 适配器输出规范化额度事件 → Worker 更新对应 runtime 快照 → 既有运行时报告/心跳 → Home 保存 → 既有页面展示。

- 事件只能更新来源设备、CLI 对应的额度，不能修改任务状态、登录状态、模型选择或账号。
- 只接收有限、合法的窗口字段；无字段不覆盖已有值，旧事件不能覆盖新样本。
- 保留真实 `quotaCheckedAt`，不能用心跳或安装检查时间冒充额度更新时间。
- 每个窗口按自身重置时间失效；过期或来源不再可信时显示旧值/未知，不自动假定额度已恢复为 100%。
- 定时运行时检测不能覆盖新收到的被动快照；重连不能把历史快照标成刚刷新。
- 登录变更、来源不明、版本缺字段必须保守处理，不能把旧账号的额度作为当前账号的有效数据。
- 后台接收额度不追加聊天文本，不触发排队、执行、登录或凭据写入。
